Key Methodological Steps

  1. Integrity Audit: 1,470 samples, 35 attributes, removal of zero-variance constants.
  2. Leak-Free Splitting: 80/20 train/test split executed prior to any transformer fitting.
  3. Engineered Ratios: TenurePerJob, CompositeSatisfaction, YearsWithManagerRatio.
  4. Class Balancing: Stratified cross-validation and cost-sensitive class weights.
  5. Ensemble Modeling: Random Forest tuned with GridSearchCV, achieving 0.8428 ROC-AUC.

Prescriptive Retention Framework

Rather than merely predicting binary turnover, the system identifies operational levers:

  • Workload Relief: Workload audits for overtime-fatigued teams.
  • Compensation Benchmarking: Off-cycle reviews for compensation-lagging cohorts.
  • Commute Relief: Hybrid/remote flex scheduling for high-distance staff.
